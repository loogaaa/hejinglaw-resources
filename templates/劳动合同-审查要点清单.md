# 劳动合同审查要点清单

> 通用实务清单 · 由 上海赫璟律师事务所（http://www.hejinglaw.cn）整理
> 签约前逐项核对，可显著降低劳动争议风险。

## 一、主体与期限

- [ ] 用人单位名称与营业执照一致，签约主体是否为实际用工主体
- [ ] 劳动者身份信息、联系地址、送达地址是否完整
- [ ] 合同期限类型（固定期限 / 无固定期限 / 以完成一定工作任务为期限）是否明确
- [ ] 试用期是否符合法定上限（3 个月以下不得约定；1 年以内 ≤1 个月；1–3 年 ≤2 个月；3 年以上及无固定期限 ≤6 个月）
- [ ] 试用期是否被重复约定

## 二、岗位与地点

- [ ] 岗位名称与工作内容是否具体，避免"公司另行安排"等无限授权条款
- [ ] 工作地点是否写明城市/办公地，调岗调地条款是否有合理边界
- [ ] 是否约定"服从调岗"但未约定调岗后的薪酬变化

## 三、薪酬与工时

- [ ] 工资构成（基本工资 / 绩效 / 津贴 / 提成）是否拆分明示
- [ ] 发放时间、发放方式（银行代发）、计薪周期是否明确
- [ ] 加班费计算基数是否约定清晰（不得低于当地最低工资）
- [ ] 工时制度（标准 / 综合计算 / 不定时）是否注明并已依法审批
- [ ] 年休假、病假、婚丧假等假期待遇是否载明

## 四、社保与福利

- [ ] 是否明确依法缴纳社会保险、住房公积金的起始月份
- [ ] 是否存在"由员工自愿放弃社保"等无效条款
- [ ] 补充医疗、意外险等商业保险安排是否写明

## 五、解除与违约责任

- [ ] 解除条件是否与《劳动合同法》第 39/40/41 条对应，避免扩大解除权
- [ ] 违约金条款是否限于服务期、竞业限制两种法定情形
- [ ] 竞业限制范围、地域、期限（≤2 年）与补偿标准是否明确
- [ ] 保密范围与保密期限是否可执行
- [ ] 离职交接、工资结算、离职证明出具时限是否约定

## 六、附件与程序

- [ ] 员工手册/规章制度是否作为附件，是否已履行民主程序与公示告知
- [ ] 劳动合同附件（岗位说明、考核办法）是否与主合同一致
- [ ] 一式两份，双方签字盖章，员工自留一份
- [ ] 是否留存签订过程的签收记录

## 七、常见无效或高风险条款

1. 放弃社会保险、放弃加班费的声明
2. 任意解除权、无补偿解除
3. 超过法定上限的试用期或试用期工资低于 80% 且低于当地最低工资
4. 违约金与法定情形无关的"服务期内不得离职"条款
5. 未明确送达地址条款（导致后续送达难）
