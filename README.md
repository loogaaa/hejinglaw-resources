## 使用说明

1. 模板为**通用格式**，请按自身案情增删事实与证据条目。
2. 提交前确认管辖法院/仲裁委名称、当事人身份信息、诉讼请求金额。
3. 涉及标的较大、时效临近或多方主体的案件，建议先咨询执业律师。
4. 模板可直接复制使用，无需授权；**不构成法律意见，不建立委托关系**。
